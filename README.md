# Interactive Math Dashboard (Vue + TypeScript)

This project is a Vue 3 + TypeScript dashboard focused on mathematical input and variable management.

## Features

- Math input field powered by MathLive (`<math-field>`)
- Variable management (add/update scalar and vector variables)
- Saved history snapshots (expression + variable count)
- Variable filtering by name and type
- Element-wise vector operations (`+`, `-`, `*`, `/`)

## Project Setup

```sh
npm install
```

### Run in development

```sh
npm run dev
```

### Unit tests

```sh
npm run test:unit -- --run
```

### Lint

```sh
npm run lint
```

### Build

```sh
npm run build
```
